## 1. HDR 环境图很适合，但不要太花

你的模型是一个**工业厂房 / 水厂泵站**，我不建议用那种特别明显的 HDRI：

- 城市街道
- 客厅
- 山顶
- 森林

否则会显得模型像悬浮在环境里。

更适合：

- 阴天工业环境
- 空旷地面
- 柔和天空
- 简单的 studio / warehouse HDR

HDR 主要给你两个东西：

### 环境反射

比如金属设备会有自然的反射。

### 环境光

模型不会只有一面亮、一面全黑。

Three.js 里大概这样：

```js
import { RGBELoader } from 'three/examples/jsm/loaders/RGBELoader.js';

new RGBELoader().load('/hdr/industrial.hdr', (texture) => {
  texture.mapping = THREE.EquirectangularReflectionMapping;

  scene.background = texture;
  scene.environment = texture;
});
```

如果你觉得 HDR 背景太抢眼，可以：

```js
scene.background = new THREE.Color('#cfd8dc');
scene.environment = hdrTexture;
```

也就是说：

> HDR 只负责给模型打环境光和反射，背景用纯色或天空。

我觉得这个反而比较适合你这种**工业监控系统**。

# 2. 视角完全可以只围绕模型

这个其实就是 `OrbitControls` 的核心用途。

你可以限制：

- 不能离模型太远
- 不能钻到模型里面
- 不能跑到地下
- 只能围绕厂房旋转
- 缩放有最大最小距离
- 限制上下观看角度

例如：

```js
const controls = new OrbitControls(camera, renderer.domElement);

controls.enableDamping = true;

// 围绕模型中心
controls.target.set(0, 5, 0);

// 最远距离
controls.maxDistance = 50;

// 最近距离
controls.minDistance = 5;

// 限制上下旋转
controls.maxPolarAngle = Math.PI / 2.05;
controls.minPolarAngle = Math.PI / 6;
```

效果就是：

```text
             Camera
                ●
              ／
            ／
        ┌───────┐
        │ 泵站   │ ← target
        │ 厂房   │
        └───────┘
```

相机永远围绕：

```js
controls.target;
```

旋转。

所以你说的：

> 能不能视角只围绕这个模型，就像玩游戏一样

**完全可以。**

# 3. 我建议不要手写 `(0, 5, 0)`，自动计算模型中心

因为你的两个 GLB：

```text
内部模型
外墙模型
```

以后可能模型大小不同。

加载完成后直接计算整个模型的包围盒：

```js
const box = new THREE.Box3().setFromObject(model);

const center = box.getCenter(new THREE.Vector3());
const size = box.getSize(new THREE.Vector3());
```

然后：

```js
controls.target.copy(center);
```

这样不管模型：

```text
100 米
20 米
500 米
```

都能自动把控制中心定位到模型中心。

相机距离也可以自动算。

```js
const maxSize = Math.max(size.x, size.y, size.z);

const distance = maxSize * 1.5;

camera.position.set(center.x + distance, center.y + distance * 0.8, center.z + distance);
```

这个我比较推荐。

## 模式二：自动巡航 ⭐

例如：

```text

内部视角
```

你这个水厂项目很适合。

# 5. 内部模型 + 外墙，我特别建议做“剖切/隐藏外墙”

你前面说还有一个外墙模型。

我觉得最终可以这样设计：

```text
┌──────────────────────────────┐
│ [整体] [内部] [设备状态]       │
│                              │
│        外墙正常显示            │
│      ┌─────────────┐          │
│      │             │          │
│      │   泵站      │          │
│      │             │          │
│      └─────────────┘          │
│                              │
└──────────────────────────────┘
```

点击：

```text
[内部]
```

外墙：

```text
opacity: 1
    ↓
opacity: 0
```

内部设备显示。

或者更高级一点：

```text
opacity: 1
    ↓
opacity: 0.15
```

变成半透明。

Three.js：

```js
wall.traverse((child) => {
  if (child.isMesh) {
    child.material = child.material.clone();

    child.material.transparent = true;
    child.material.opacity = 0.15;
  }
});
```

这样用户可以：

> 看见整个厂房结构，同时又能看到里面的水泵设备。

这个效果很适合数字孪生。

# 6. 灯光我建议 HDR + 一盏太阳光

不要搞太多灯。

推荐：

```text
HDR Environment
       +
DirectionalLight
       +
Ground Shadow
```

例如：

```js
const light = new THREE.DirectionalLight(0xffffff, 2);

light.position.set(10, 20, 10);

light.castShadow = true;

scene.add(light);
```

然后：

```js
renderer.shadowMap.enabled = true;
```

地面：

```js
const ground = new THREE.Mesh(
  new THREE.PlaneGeometry(200, 200),
  new THREE.MeshStandardMaterial({
    color: '#b0b5b8',
  })
);

ground.rotation.x = -Math.PI / 2;
ground.receiveShadow = true;

scene.add(ground);
```

这样模型就不会有那种：

> 黑色背景 + 模型悬浮在空气中

的感觉。

# 7. 如果想要“玩游戏”的感觉，可以限制相机活动范围

这个很重要。

普通 OrbitControls：

```text
用户可以
↖ ↗ ↘ ↙
360°
```

但泵站模型可能不需要用户钻到：

```text
地下 ❌
屋顶里面 ❌
墙壁内部 ❌
模型背后很远 ❌
```

你可以做成：

```js
controls.minDistance = maxSize * 0.8;
controls.maxDistance = maxSize * 2.5;

controls.minPolarAngle = Math.PI * 0.15;
controls.maxPolarAngle = Math.PI * 0.48;
```

这样用户只能：

```text
       ↖ ↑ ↗
        \|/
     [泵站模型]
```

在一个合理范围内观察。

这就会比普通 Three.js Demo 更像一个完整产品。
