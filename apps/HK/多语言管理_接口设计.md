# 多语言管理模块 - 接口设计文档

> 基础路径：`/eam-service-system`
> 数据格式：JSON
> 字符编码：UTF-8
> 鉴权方式：Header 中携带 `Authorization: Bearer {token}`

---

## 一、统一响应格式

**JSON 结构**：

```json
{
  "code": 200,
  "description": "操作成功",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 状态码，200=成功，其他=失败 |
| description | string | 说明信息 |
| data | object/array | 业务数据，泛型T |

### 分页响应结构

分页接口的 `data` 为分页对象，结构如下：

```json
{
  "code": 200,
  "description": "操作成功",
  "data": {
    "list": [],
    "total": 100,
    "pageSize": 15,
    "page": 1
  }
}
```

---

## 二、语言管理接口

### 1. 语言列表（分页）

**接口地址**：`GET /eam-service-system/language/page`

**请求参数（Query）**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| langName | string | 否 | 语言名称（模糊查询） |
| langCode | string | 否 | 语言编码（模糊查询） |
| status | int | 否 | 状态：0-禁用，1-启用 |
| page | int | 否 | 当前页，默认1 |
| pageSize | int | 否 | 每页条数，默认15 |

**响应数据 data.list**：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 主键ID |
| langName | string | 语言名称 |
| langCode | string | 语言编码 |
| isDefault | int | 是否默认：0-否，1-是 |
| sort | int | 排序号 |
| status | int | 状态：0-禁用，1-启用 |
| createTime | Date | 创建时间 yyyy-MM-dd HH:mm:ss |

**响应示例**：

```json
{
  "code": 200,
  "description": "操作成功",
  "data": {
    "list": [
      {
        "id": "1001",
        "langName": "简体中文",
        "langCode": "zh_cn",
        "isDefault": 1,
        "sort": 1,
        "status": 1,
        "remark": "系统默认语言",
        "createTime": "2023-05-05 11:49:00"
      }
    ],
    "total": 3,
    "pageSize": 15,
    "page": 1
  }
}
```

---

### 2. 新增语言

**接口地址**：`POST /eam-service-system/language`

**请求体（Body JSON）**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| langName | string | 是 | 语言名称，最大64字符 |
| langCode | string | 是 | 语言编码，如 zh_cn，唯一，最大32字符 |
| isDefault | int | 否 | 是否默认：0-否，1-是，默认0 |
| sort | int | 否 | 排序号，默认0 |
| status | int | 否 | 状态：0-禁用，1-启用，默认1 |

**请求示例**：

```json
{
  "langName": "日本語",
  "langCode": "ja_jp",
  "isDefault": 0,
  "sort": 4,
  "status": 1
}
```

**响应数据**：返回新增记录的ID

```json
{
  "code": 200,
  "description": "新增成功",
  "data": 1004
}
```

**业务规则**：
- `langCode` 全局唯一，重复返回错误码提示
- 若 `isDefault=1`，需将其他语言的 `isDefault` 置为0（全局只能有一个默认语言）

### 3. 编辑语言

**请求体（Body JSON）**：

| langName | string | 是 | 语言名称 |
| langCode | string | 是 | 语言编码 |
| isDefault | int | 否 | 是否默认 |
| sort | int | 否 | 排序号 |
| status | int | 否 | 状态 |

**响应示例**：

```json

```

### 4. 删除语言

**接口地址**：`DELETE /eam-service-system/language`

**路径参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 语言ID |

**响应示例**：

```json
{
  "code": 200,
  "description": "删除成功",
  "data": null
}
```

**业务规则**：
- 默认语言（`isDefault=1`）不允许删除
- 删除语言时，同步逻辑删除 `tbl_key_value` 中该 `langCode` 对应的所有翻译记录

### 5. 语言详情

**接口地址**：`GET /eam-service-system/language`

**路径参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 语言ID |

**响应数据**：同列表单条记录结构

---

### 6. 所有启用语言列表

**接口地址**：`GET /eam-service-system/language/list`

**说明**：返回所有启用状态的语言，用于词条管理页表头动态渲染、前端语言切换等场景。

**响应数据 data**：数组，每项含 `id`、`langName`、`langCode`、`isDefault`、`sort`

```json
{
  "code": 200,
  "description": "操作成功",
  "data": [
    { "id": "1001", "langName": "简体中文", "langCode": "zh_cn", "isDefault": 1, "sort": 1 },
    { "id": "1002", "langName": "繁体中文", "langCode": "zh_hk", "isDefault": 0, "sort": 2 },
    { "id": "1003", "langName": "English", "langCode": "en_us", "isDefault": 0, "sort": 3 }
  ]
}
```

## 三、词条管理接口

### 1. 词条列表（分页，行转列）

**接口地址**：`GET /eam-service-system/languageEntry/page`

**说明**：按 `i18n_key` 分组，将每种语言的翻译作为一列返回，前端直接渲染表格。

**请求参数（Query）**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| i18nKey | string | 否 | 词条Key（模糊查询） |
| page | int | 否 | 当前页，默认1 |
| pageSize | int | 否 | 每页条数，默认15 |

**响应数据 data.list**：

每条记录为扁平化结构，`i18nKey`、`remark` 为固定字段，各语言翻译直接以语言编码作为字段名（动态字段，随系统已启用语言变化）。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 主键ID |
| i18nKey | string | 词条Key |
| zh_cn | string | 简体中文 |
| zh_hk | string | 繁体中文 |
| en_us | string | 英文     |
| createTime | string | 创建时间 |

**响应示例**：

```json
{
  "code": 200,
  "description": "操作成功",
  "data": {
    "list": [
      {
          "id":"1001",
        "i18nKey": "sys.user.name",
        "zh_cn": "用户名",
        "zh_hk": "使用者名稱",
        "en_us": "Username",
        "createTime": "2023-05-05 12:00:00"
      }
    ],
    "total": 5,
    "pageSize": 15,
    "pageNum": 1
  }
}
```

> **设计说明**：语言翻译以语言编码作为扁平化字段，新增语言后列表自动多出对应字段列，前端按语言列表动态渲染表头即可。

---

### 2. 新增词条

**接口地址**：`POST /eam-service-system/languageEntry`

**说明**：一次提交一个词条Key及所有语言的翻译，后端批量插入 `tbl_key_value`（每种语言一条记录）。

**请求体（Body JSON）**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| i18nKey | string | 是 | 词条Key，如 sys.user.name，唯一，最大128字符 |
| zh_cn | string | 是 | 简体中文 |
| zh_hk | string | 是   | 繁体中文 |
| en_us | string | 是 | 英文 |

**请求示例**：

```json
{
  "i18nKey": "sys.user.email",
    "zh_cn": "邮箱",
    "zh_hk": "電子郵箱",
    "en_us": "Email"
}
```

**响应示例**：

```json
{
  "code": 200,
  "description": "新增成功",
  "data": null
}
```

**业务规则**：
- `i18nKey` 全局唯一（同一Key不能重复新增）
- `values` 中未包含的语言，不插入记录（或插入空字符串，由业务决定）
- 每条翻译记录的 `id` 由应用层雪花算法生成

---

### 3. 编辑词条

**接口地址**：`PUT /eam-service-system/languageEntry`

**说明**：按 `i18nKey` 更新所有语言的翻译。采用「先删后插」策略：逻辑删除该Key下所有旧翻译，再插入新翻译。

**请求体（Body JSON）**：同新增词条

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | string | 是 | 数据记录ID |
| i18nKey | string | 是 | 词条Key（不可修改，作为定位条件） |
| zh_cn   | string | 是   | 简体中文                          |
| zh_hk | string | 是 | 繁体中文 |
| en_us | string | 是 | 英文 |

**响应示例**：

```json
{
  "code": 200,
  "description": "修改成功",
  "data": null
}
```

---

### 4. 删除词条

**接口地址**：`DELETE /eam-service-system/languageEntry`

**路径参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | string | 是 | 词条记录ID |

**说明**：逻辑删除该 `i18nKey` 下所有语言的翻译记录。

**响应示例**：


### 6. 按语言编码加载语言包（前端用）

**接口地址**：`GET /eam-service-system/languageEntry/load`

**路径参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| langCode | string | 是 | 语言编码，如 zh_cn |

**说明**：前端初始化或切换语言时调用，一次性加载该语言下所有词条的 key-value 映射，用于前端 i18n 渲染。建议加缓存（如Redis），减少数据库查询。

**响应数据 data**：键值对对象，key为词条Key，value为翻译内容

```json
{
  "code": 200,
  "description": "操作成功",
  "data": {
    "sys.user.name": "用户名",
    "sys.user.password": "密码",
    "menu.dashboard": "仪表盘",
    "common.confirm": "确认",
    "common.cancel": "取消"
  }
}
```

## 五、关键设计说明

1. **词条表合并设计**：`tbl_key_value` 一条记录 = 一个Key的一种语言翻译，通过 `i18n_key + lang_code` 唯一约束。列表接口用 `GROUP BY i18n_key` 行转列，动态返回所有语言翻译。

2. **编辑词条策略**：采用「逻辑删除旧记录 + 批量插入新记录」，避免逐条 update 的复杂判断，保证数据一致性。

3. **语言包加载接口**：前端切换语言时一次性拉取全部词条，建议接入 Redis 缓存，key 为 `i18n:{langCode}`，词条变更时清除缓存。

4. **默认语言唯一**：新增/编辑语言时若设为默认，需事务内将其他语言 `is_default` 置0。

5. **删除语言级联**：删除语言时同步逻辑删除该语言下所有词条翻译，避免孤儿数据。
