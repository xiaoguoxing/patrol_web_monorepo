# 送水泵房三维模型说明文档（pump-house.glb）

> 版本：v1.1 ｜ 更新日期：2026-09-22 ｜ 适用对象：需要接收、查看或二次开发本模型的工程师/设计人员

---

## 1. 模型概述

本模型是一座**自来水厂送水泵房**的完整三维场景，核心工艺设备为 **5 组立式长轴离心泵组（P-1 ～ P-5）**，结构形式为「**立式电机在上、水泵本体在下（泵坑内）**」。

模型依据香港水务署图纸 **W8141·01·129**（马鞍山净水厂及输水设施——泵站首层局部平面，图签：CDM / P2H，1997 年竣工图）的建筑风格还原：8000 mm 柱网模数、2460 mm 宽高位排窗带、600 mm 高女儿墙屋面、400×400 屋顶排风孔等布置特征均取自该图。**所有尺寸为示意比例，泵组参数为展示示意值，不得直接用于施工或采购。**

源场景为 Three.js 实时漫游工程（React + Vite）。本 GLB 最初由官方 GLTFExporter 从同一场景导出，v1.1 又在 GLB 中移除了室外网格地面并整理了外立面节点，其他几何、材质与贴图保留原导出内容。

## 3. 坐标系、单位与空间范围

- **单位：米（m）**，模型按真实工程尺度 1:1 建模。
- glTF 标准 **Y-up 右手坐标系**（导出时已自动从 three.js 的坐标习惯转换）。
- **原点 (0, 0, 0) 位于泵房室内地坪几何中心**，泵组一字排开于 X 轴上。
- 轴向约定：

| 轴 | 方向含义 |
|---|---|
| +X | 沿泵列方向，5 组泵位于 X = -8 / -4 / 0 / +4 / +8 |
| +Y | 竖直向上（地坪 Y=0，屋面檐口约 Y=8.75） |
| +Z | 指向送水总管一侧墙面（总管位于 Z≈+7.32） |

- 整体包围盒：约 **26.05 m（X）× 13.55 m（Y）× 18.25 m（Z）**；已移除原 `node196` 对应的 220×220 m 室外网格地面，建筑本体约 24×16×8.5 m。**对接其他模型时建议以「泵房中心」或「P-3 泵组中心」为对齐基准**。

## 4. 场景结构总览

场景按以下逻辑分组（对应导出后的节点树）：

```
Scene
├── 建筑组            室内地坪/泵坑/屋面/屋顶排风机/灯具等
│   └── 外立面        四面外墙/壁柱/高排窗/大门/女儿墙/雨棚
├── 泵组 P-1 … P-5    每台泵一个分组，含电机、出水室、水下泵体、支管、蝶阀、护栏
├── 送水总管          沿 +Z 墙的 DN900 主管及 5 个接管支墩
├── 桥式起重机        大车轨道（固定）+ 桥架/小车/吊钩（可整体平移的独立组）
├── 低压配电柜 MCC    8 面柜体 + 与泵组联动的红/绿指示灯
├── 中控值班台        桌体 + 3 台显示器（屏幕自发光）
├── 厂房高杆灯 ×8     发光灯罩（自发光材质）
└── 灯光              1 盏平行光（日光）+ 4 盏点光源（KHR_lights_punctual）
```

> 漫游页中的 HTML 悬浮文字标注（CSS2D）不属于三维几何，**未包含在 GLB 中**。

> v1.1 将原建筑组内的 55 个外立面直接子对象归入名为 `外立面` 的独立组；该组含下级窗框和玻璃等节点。原 `node196` 的网格地面节点及其网格已删除。节点索引因此重新编号，查找时请使用组名。

### 5.3 每台泵的出水管线

- 出水横管 **Ø0.60**，中心标高 Y=+0.62，自泵中心沿 +Z 方向接至 Z≈7.4 的送水总管；
- 管上设 **法兰（Z≈4.9）+ 蝶阀（Z≈5.25）+ 红色手轮**（Ø0.4，含 3 根辐条）；
- 支管中设一处钢制支墩（Z≈2.9）；
- 每台泵支管外壁覆有一层**流向箭头贴图管**（半透明自发光，默认透明度为 0——见 §9 注意事项第 5 条）。

### 5.4 泵坑与安全设施

- 圆形泵坑开口 **Ø2.5（半径 1.25），深 3.6 m**，坑壁为混凝土；
- 坑沿设混凝土护棱；坑后半部覆**半开式花纹钢盖板**（可拆卸示意）；
- 靠走道侧设 **黄色弧形安全护栏**（半径 1.75 m，双层扶手 + 踢脚挡板，开口朝泵后）。

## 11. 对接与二次开发注意事项

1. **纯静态模型**：无动画、无骨骼、无变形器；起重机车、流向层等「可动件」是独立节点，直接改 `position` 即可做简单动画。
2. **尺寸与参数为示意值**：柱网、窗洞取自 W8141·01·129 的布置风格，泵组按典型立式长轴泵夸张简化（如省略地脚螺栓、填料函细节），**禁止用于加工图、碰撞检测净距校核**。
3. **材质未命名**：程序化生成时未写入 `name` 字段，请按 §7 对照基色识别，或在源工程 `src/scene/pumpHouse.ts` 的 `M` 材质表中按索引核对。
4. **流向箭头层默认隐藏**：材质 26/33/37/41/45 的 alpha=0，叠加在每泵出水支管外壁；如需显示，把对应材质透明度调到 0.9 左右即可（源工程中由「启停状态」驱动并做 UV 滚动）。
5. **玻璃与水面为透明材质**：部分渲染器需开启透明排序/混合模式才能正确显示。
6. **泵坑底部在 -3.6 m**：从室内地坪视角看不到水下泵体属正常；如需展示，在引擎中隐藏地坪网格（GLB 中室内地坪为独立网格，即贴图 #1 的网格）即可复现漫游页的「地板剖视」效果。
7. **接收坐标系**：glTF 为 Y-up；若接入 CAD（Z-up）流程，导入后统一绕 X 轴旋转 -90°。
8. **建议对齐基准**：泵房地坪中心 (0,0,0)，或 P-3 泵组轴线 (0, 0, 0)——Z=0 处。

## 12. 修改与重新导出

原源工程目录为 `pump-house-3d/`（React + TypeScript + Vite + Three.js；本次提供的文件中未包含该目录）：

```bash
cd pump-house-3d
npm install            # 如未安装过依赖
npm run dev            # 本地预览 http://localhost:3000
```

场景代码：`src/scene/pumpHouse.ts`（建筑/泵组/材质）、`src/scene/textures.ts`（程序化贴图）、`src/pages/Home.tsx`（交互与相机）。

**重新导出 GLB**（已内置自动化）：

```bash
node node_modules/vite/bin/vite.js --port 3123 &   # 起 dev 服务
node export-glb.cjs pump-house.glb                  # 无头浏览器抓取 GLB
```

`export-glb.cjs` 通过 `#exportglb` 路由触发页面内的 GLTFExporter，生成原始静态 GLB。

**v1.1 说明：**外立面分组和室外网格地面移除是在本 GLB 中直接完成的；上述源工程重新导出流程尚未同步这两项修改，重新导出后需再次应用。
